What is the Set Cover Problem?

Given a universe U of n elements and a collection C of subsets of U, and an integer k, does there exist a sub-collection of at most k sets whose union equals U?

Formal Definition

Input: Universe U = {e₁, e₂, …, eₙ}, sets S₁, S₂, …, Sₘ ⊆ U, integer k
Question: ∃ sub-collection {Sᵢ₁, …, Sᵢₜ} ⊆ C with t ≤ k such that Sᵢ₁ ∪ … ∪ Sᵢₜ = U?

Real-World Applications

  • Facility location: Fewest warehouses to serve all cities
  • Wireless coverage: Fewest base stations to cover all zones
  • Species habitat: Fewest reserves to protect all species
  • Software testing: Fewest test cases to cover all code paths

Why is it Hard?

Set Cover is NP-complete. No polynomial-time exact algorithm is known. With m subsets, brute-force tries all 2ᵐ sub-collections — infeasible for large inputs. A common practical approximation approach is the greedy O(ln n)-approximation.

📚 Worked Example ▼

U = {1, 2, 3, 4, 5}  |  S₁={1,2,3}, S₂={2,4}, S₃={3,4,5}, S₄={4,5}  |  k = 2

Greedy Execution:

Step 1: Uncovered = {1,2,3,4,5}. Count coverage of each set:
|S₁∩Uncov| = 3, |S₂∩Uncov| = 2, |S₃∩Uncov| = 3, |S₄∩Uncov| = 2.
Pick S₁ (ties broken by index). Uncovered = {4, 5}.
Step 2: Uncovered = {4,5}. |S₂∩Uncov|=1, |S₃∩Uncov|=2, |S₄∩Uncov|=2.
Pick S₃. Uncovered = ∅. Done!
Result: Greedy cover = {S₁, S₃}. Size = 2 = k. ✓ Optimal!

Counterexample: Greedy is not always optimal

U={1,2,3,4,5,6,7}, S₁={1,2,3,4}, S₂={1,2,5,6}, S₃={3,4,5,7}.
Optimal: {S₂, S₃} (size 2) — S₂∪S₃ = {1,2,3,4,5,6,7} = U. ✓
Greedy: Step 1 picks S₁ (4 new elements). Step 2 picks S₂ (2 new: 5,6). Step 3 picks S₃ (1 new: 7). Total = 3 sets.
Greedy uses 3 sets vs optimal 2. The approximation ratio here is 3/2 ≤ H(7) ≈ 2.59. Bound holds. ✓

We prove Set Cover is NP-complete by showing (1) it is in NP, and (2) Vertex Cover reduces to it in polynomial time.

✅ Step 1: Set Cover is in NP ▼

Certificate

A proposed solution is a sub-collection T ⊆ C of at most k sets.

Verifier

Given T, a polynomial-time verifier:
1. Checks |T| ≤ k  — O(1)
2. Computes ⋃S∈T S  — O(k·n)
3. Checks the union equals U  — O(n)
Total: O(k·n) = polynomial. ✓

🔗 Step 2: Reduction from Vertex Cover to Set Cover ▼

Construction

Given a Vertex Cover instance (G = (V, E), k), construct a Set Cover instance:

  • Universe U = E  (each edge becomes an element)
  • For each vertex v ∈ V, create set Sv = { e ∈ E : e is incident to v }
  • Use the same k

Time: O(|V| + |E|) to enumerate vertices and edges — polynomial. ✓

Correctness Proof

Forward Direction (⟹)

If G has a vertex cover C* of size k:
For each vertex v ∈ C*, include Sv in our set cover T.
Every edge e=(u,w) ∈ E is covered by some vertex in C*, say u.
Therefore e ∈ Su ⊆ ⋃v∈C*Sv.
So T covers all of U=E, and |T| = |C*| ≤ k. ✓

Backward Direction (⟸)

If there is a set cover T ⊆ {Sv} with |T| ≤ k:
Let C* = { v : Sv ∈ T }.
For any edge e=(u,w) ∈ E=U, since T covers U, ∃ Sv ∈ T with e ∈ Sv.
Since e ∈ Sv, vertex v is one endpoint of edge e. Therefore at least one endpoint of e is in C*, so e is covered.
So every edge is covered, and |C*| = |T| ≤ k. ✓

Conclusion

The reduction is polynomial, and G has a vertex cover of size k if and only if the constructed Set Cover instance has a cover of size k. Since Vertex Cover is NP-complete, Set Cover is NP-hard. Combined with Step 1 (Set Cover ∈ NP), Set Cover is NP-complete. □

🧮 Approximation Ratio Analysis ▼

Theorem (Chvátal 1979)

The greedy algorithm achieves an approximation ratio of H(n) = 1 + 1/2 + 1/3 + … + 1/n ≈ ln n, where n = |U|. This ratio is tight for this specific algorithm — stronger inapproximability lower bounds exist in the literature (e.g., Dinur & Steurer 2014 show that achieving a ratio of (1−ε)ln n is NP-hard for any ε>0), but those require more advanced reductions. For this course, the key result is that greedy achieves H(n) and no polynomial-time algorithm is known to exactly solve Set Cover.

Harmonic Number Argument

Let OPT = optimal cover size. When the greedy algorithm picks a set, at least 1/OPT fraction of the remaining uncovered elements get covered. After OPT·ln(n) steps, fewer than 1 element remains uncovered (by repeated halving). So greedy uses at most OPT·H(n) sets.
